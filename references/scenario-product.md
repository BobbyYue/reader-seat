# Product Introduction, Launch Note, And PRD

## Reader Task

Enable the reader to identify the target user and problem, understand the value and evidence, distinguish capability from promise, and judge scope or next action.

## Required Content

- target user or segment and the relevant context;
- user problem, unmet need, or job to be done;
- value proposition expressed as an outcome, not a feature list;
- core capabilities and evidence supporting material claims;
- scope, exclusions, limitations, dependencies, and known risks;
- success metrics and measurement plan for PRDs or launch decisions;
- appropriate next step, such as try, review, approve, adopt, or monitor, only when needed.

## Recommended Relationship

`target user and problem -> value proposition -> capabilities and supporting evidence -> boundaries and risks -> usage, success measures, or next action`

For PRDs, add assumptions, requirements, prioritization, edge cases, and rollout. For product introductions, emphasize inspectable value and avoid implementation detail that does not affect adoption.

## Evidence Requirements

- Support claims with user research, usage data, experiments, benchmarks, or clearly labeled assumptions.
- Define decision-critical metrics locally even when their abbreviations are familiar.
- Distinguish current capability, planned capability, aspiration, and unsupported marketing language.
- State who is not served or which cases are out of scope when that changes expectations.

## Common Failures

- features substituted for user value;
- target user described as “everyone” or left implicit;
- benefits expressed with unmeasured superlatives;
- scope, failure cases, or limitations omitted;
- success metric unrelated to the user problem;
- call to action stronger than product readiness or evidence.

## Acceptance Questions

1. Can the reader identify the intended user and problem?
2. Can they restate the value without repeating a feature list?
3. Can they distinguish available capability, future plan, and limitation?
4. Are important claims supported or labeled as assumptions?
5. Is success measurable and the next step appropriate to readiness?
