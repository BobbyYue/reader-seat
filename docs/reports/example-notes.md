# AI and Work Example: Generation and Review

## English

The bilingual example began with the research prompt shown in the README, using
Reader's Seat 0.36. It was then revised in response to user feedback, including
the request for data visualizations on 23 October 2026. The screenshots show the
actual report. This is an edited example, rather than a one-shot quality claim.

The evidence snapshot was checked on 22 October 2026. The visual update reuses
that snapshot; its publication date does not imply a new research search.
Research findings, the report author's role analysis and conditional scenarios
are distinguished in the text. The three charts retain the source populations,
units, comparison periods and relevant uncertainty.

The original generation passed its latest source, readability and visual checks,
but did not complete the full review requirement: the independent reader's
retelling did not demonstrate a concrete role-specific application that the
report was intended to convey. The workflow's incomplete-draft exit also
remained unresolved. Those results have not been relabelled as passes.

The visualization update checks the changed data displays, source attribution,
rendering, language links and access to values without JavaScript. It does not
establish a new full independent-review pass or comparable results across agents.

To read offline, clone/download the repository and open either HTML file in
`docs/reports/`. Keep its `assets/` and `_shared/` folders alongside it. The latter
contains ECharts and Work Sans with their licenses.
